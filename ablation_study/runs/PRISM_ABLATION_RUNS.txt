PRISM architectural ablations (MOSI, frozen Optuna trial234 hyperparameters)

Where code and argv live
  All training uses My_creation/ablation_study/train.py.
  Trial 234 knobs are defined in ablation_study/mosi_trial234_hparams.py (numeric block
  mirrored from fixed_experiment/mosi_trial234_hparams.py; update fixed first, then diff-sync).
  Baseline (--ablation none) uses infogate_modules_fixed.py — a verbatim copy of
  fixed_experiment/infogate_modules.py (see deberta_infogate.py / bert_infogate.py). Re-sync
  that file from fixed_experiment when the frozen baseline module changes. PRISM modes use
  infogate_modules.py. fixed_experiment/ remains the reference snapshot for the baseline file.

Argv
  build_train_argv(checkpoint_dir=..., ablation=...) matches the fixed baseline argv when
  ablation is none (no --ablation flag). Non-none modes append --ablation <mode> only.

Launcher and batch
  python -u ablation_study/train_fixed_mosi_trial234.py [--ablation ...] [--checkpoint-dir ...]
  Six-mode batch script:
    bash ablation_study/run_prism_ablations_mosi_trial234.sh
  Scheduling: if the machine reports two GPUs, the script uses GPU 0 and GPU 1. With
  JOBS_PER_GPU unset, the default layout is 2 concurrent trainings on GPU0 and 1 on GPU1
  (three slots per wave). Override explicitly, e.g.:
    GPU_LIST=0,1 JOBS_PER_GPU=2,1
  Same count per GPU:
    JOBS_PER_GPU=2
  For machines with != 2 GPUs and no GPU_LIST, ids are taken from nvidia-smi order while
  skipping EXCLUDE_GPUS (unset → default skip GPU 1).

Baseline certification (match frozen Best Results)
  Run none as the only training process on the chosen GPU (no second job on the same card).
  Compare Epoch 1–2 and Best Results with fixed_experiment/runs/mosi_trial234/train.log.
  nohup (recommended):
    CUDA_VISIBLE_DEVICES=0 bash ablation_study/run_none_solo_frozen_align_nohup.sh
  Logs/checkpoints default to ablation_study/runs/mosi_trial234_none_solo/ (override with OUT=/path).
  After run: diff-style check vs frozen — see ablation_study/runs/MOSI_TRIAL234_NONE_SOLO_COMPARE.txt

Output layout
  Baseline (--ablation none):
    ablation_study/runs/mosi_trial234/train.log
    ablation_study/runs/mosi_trial234/checkpoints/infogate_mosi_best.pt
  Other modes:
    ablation_study/runs/mosi_trial234_<mode>/train.log
    ablation_study/runs/mosi_trial234_<mode>/checkpoints/infogate_mosi_best.pt

Metrics in logs
  Training prints Dev/Test lines each epoch via fmt_metrics (Acc2, Acc7, MAE, Corr, F1).
  End-of-run block "Best Results (<selection_metric>, epoch >= stage1+1)" reports the
  checkpoint-selected test snapshot (trial234 uses selection_metric=mae).

Checkpoint metadata
  train.py save_dict includes ablation.arch for PRISM modes. Baseline none uses the fixed
  InfoGate implementation (infogate_modules_fixed.py); argv omits --ablation.

Verification reference (frozen fixed run)
  My_creation/fixed_experiment/runs/mosi_trial234/train.log — none mode Best Results should match.
